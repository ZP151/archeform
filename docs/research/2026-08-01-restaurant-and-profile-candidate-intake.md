# Restaurant and reusable-profile candidate intake

**Research date:** 2026-08-01
**Decision investigated:** establish a small, evidence-backed Foundry intake
batch for a production-grade Restaurant Ordering profile, while adding only
reusable seams that also serve other Profiles. This is a public-source desk
research record, not an approval to install, copy, deploy, contact a vendor,
or create an account.

## Scope and guardrails

This review was checked for source overlap against
`ecosystem/portfolio/2026-07-30-external-business-logic.json`,
`docs/research/2026-08-01-100-profile-capability-ecosystem.md`,
`docs/research/2026-08-01-capability-supply-expansion-source-matrix.md`, and
`docs/research/2026-08-01-second-capability-supply-matrix.md`. It deliberately
does not repeat their candidates (for example, TastyIgniter, OSPOS, Medusa,
OpenFGA, Keycloak, Ory Kratos, Chatwoot, InvenTree, Gotenberg, OpenFGA,
Temporal, ClickHouse, Cube, OSRM, or existing document libraries).

Factory remains the authority for DomainModel, PolicyModel, FlowModel and
published facts. A provider or upstream project is never permitted to consume
a mutable Draft. Every eventual adapter must accept a Published Graph
projection only, retain credentials outside the Graph, and use a local fake
for the first conformance fixture.

For this memo:

- **Provider adapter** means a Factory-authored boundary to a separately
  governed API/service. It is not an endorsement or a procurement decision.
- **Selective source study** means inspect only the named paths at an immutable
  ref; it authorizes no copying. Whole business-suite repositories stay in this
  category unless a later, path-level record explicitly approves a port.
- **Reference only** means feature, vocabulary, and test-idea comparison only.
  No source, package, image, linking, or runtime use follows from the entry.
- A proprietary API has **no OSS licence**. Its exact governing instrument is
  named as vendor terms; no claim of an open-source licence is implied.

## Inferences and recommendation

**Inference:** Restaurant Ordering can be production-shaped without a live
payment or delivery vendor. Square's documentation proves that orders,
fulfilment, loyalty, and payments often meet in one vendor API, but that is a
reason to separate Factory seams rather than adopt its model. DoorDash's
limited production-access notice reinforces this sequencing. **Decision:**
make `restaurant.order`, `kitchen.station-ticket`, `inventory.stock-movement`,
`table.reservation`, `queue.ticket`, `loyalty.points-event`,
`delivery.dispatch-request`, and `payment-attempt` Factory concepts; provide a
deterministic fake for payment and delivery first.

**Inference:** The permissive candidates are infrastructure/provider choices,
not shortcuts to reusable business logic. Odoo is LGPL but a large vertical
suite with third-party licence variation; Operaton is Apache-2.0 but accepts a
different flow authority; SpiceDB/OPA risk importing provider policy language.
**Decision:** begin only the fixed-ref source studies and local conformance
fixtures above. No upstream code path is cleared for porting.

**Inference:** GPL/AGPL and mixed/proprietary projects are useful negative
constraints. Their feature sets expose CRM, support, booking, document, and
analytics requirements, but Factory cannot safely treat them as implementation
sources under current policy. **Decision:** retain reference-only status and
derive independently authored acceptance scenarios, never source fragments.

## Promotion gate for every non-reference candidate

Before any candidate changes classification, record the immutable tag/commit
or image digest, licence/NOTICE inventory, package or API version, source or
OpenAPI digest, SBOM, vulnerability/security-policy check, credential-isolation
plan, removal/migration path, and the listed local conformance fixture. The
fixture must demonstrate published-revision-only input, idempotency, tenant
isolation, redaction, timeout/outage handling, and that the provider cannot
write canonical Graph facts. Passing that gate is evidence only; it is not
Golden promotion or approval.
