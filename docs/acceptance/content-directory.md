# Knowledge Resource Directory local acceptance

Date: 2026-09-24. Scope: ADR-0074's local Content/Directory experiment.
Status: accepted for bounded local family delivery after attempt 3, independent
Terra QA and Sol final review at P0/P1/P2 0/0/0. PM records nine registered and
locally accepted definitions across five demonstrated runtime families. This
does not establish a hosted or mature consumer product.

## Product and surfaces

Readers find and read listed plain-text resources, primarily on a phone. Curators
create, correct, show and hide those same persisted entries, primarily in desktop
Web. Both roles retain responsive access at 390/768/1440 px. Local pinned icons,
category color and clear content hierarchy carry the interface; decorative media
is optional. Demo role selection is not authenticated identity.

The canonical definition reuses the six accepted core capability locks and the
existing Graph, immutable Publish/Compilation, runtime store and UI patterns.
This family does not promise file uploads, private membership, arbitrary external
links, reader submissions or message delivery.

## Applicable completion conditions

- Create two distinct entries, show one, find/read it as a reader, correct it,
  hide it, correct it while hidden, then show the same ID again.
- Preserve literal text and bounded queries; hidden and absent reader details
  both return 404. Reject invalid input and reader mutations without writes.
- Retain form edits on stale conflict. Retry an interrupted committed create with
  the same key/body and record; competing same-version writes admit one winner.
- Restart the generated API while retaining PostgreSQL, then replay the original
  command without extra receipts/history and verify the saved result after reload.
  This is not a PostgreSQL daemon restart.
- Inspect actual populated reader/detail and curator/input/result screenshots;
  confirm responsive controls, local assets and error/recovery states.
- Keep immutable compilation identity unchanged and prove exact owned Preview
  and outer-stack cleanup. Prior policy-blocked scratch residuals remain separate.

Source review is clear, including bounded worker comparison and the persisted-lock
correction. Independent Terra QA passes 168 focused runtime/profile/compatibility
cases; it reuses unchanged adapter, UI and worker evidence. Final review disposition
is recorded in the PM ledger. The definition index and cheap regression lane are
routing/feedback tools, not acceptance authorities.

## Delivery boundary

[Local durable delivery](local-durable-delivery.md) independently proves a
synthetic compatible upgrade, failed-candidate retention, retained-image rollback
with data intact and separate backup restore. Directory Preview remains disposable.
Neither result establishes hosted deployment, private identity, a production
deployment adapter or an uninterrupted availability guarantee.
