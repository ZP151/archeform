estimated unit price and justification. The server calculates the exact total.
Managers return requests with a reason or approve them; finance reads decisions.

resubmission. This records approval only, with selectable local demo roles.

supplier ordering, inventory and private identity remain material exclusions.

accepted ADR-0070 calculated Approval profile. It composes existing workspace,
